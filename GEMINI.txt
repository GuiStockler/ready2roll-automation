Para te ajudar a estruturar uma bateria de testes manuais eficiente para essa aplicação de rolagem de dados (Dice Roller), dividi os cenários em categorias essenciais de Garantia de Qualidade (QA).

1. Testes Funcionais (Core Features)
Estes validam se as funcionalidades principais do sistema estão operando conforme o esperado.

TC01 - Rolagem de dado único: Selecionar um tipo de dado padrão (ex: d6 ou d20), clicar em rolar e verificar se o resultado gerado está dentro do intervalo matemático válido (ex: entre 1 e 6 para um d6).

TC02 - Rolagem de múltiplos dados: Configurar para rolar vários dados do mesmo tipo simultaneamente (ex: 3d6). Verificar se o sistema exibe tanto os valores individuais de cada dado quanto a soma total correta.

TC03 - Múltiplos tipos de dados: Selecionar diferentes dados ao mesmo tempo (ex: 1d20 + 1d6) e verificar se o cálculo final e os valores individuais são exibidos corretamente.

TC04 - Uso de modificadores: Adicionar modificadores numéricos positivos ou negativos à rolagem (ex: 1d20 + 5 ou 1d8 - 2) e validar se a operação matemática final está exata.

2. Testes de Limite e Negativos (Boundary & Negative)
Testam como o sistema lida com entradas inválidas, extremas ou cenários inesperados.

TC05 - Quantidade mínima de dados: Tentar rolar 0 dados ou tentar diminuir a quantidade abaixo do limite inferior permitido pela interface.

TC06 - Quantidade máxima de dados: Inserir um número extremamente alto de dados (ex: 9999 dados) para verificar se a aplicação trava, demora muito para responder ou estoura o limite da interface.

TC07 - Campos de texto com valores inválidos: Caso o site permita digitar valores em campos numéricos, tentar inserir letras, símbolos especiais ou números negativos e verificar a validação (bloqueio ou tratamento do erro).

TC08 - Modificadores extremos: Inserir modificadores com valores absurdamente altos ou baixos para checar se quebram o layout ou geram erros de overflow.

3. Testes de Interface e Usabilidade (UI/UX)
Verificam a experiência do usuário e a apresentação visual.

TC09 - Legibilidade dos resultados: Garantir que os números gerados sejam fáceis de ler (contraste adequado entre texto e fundo, tamanho de fonte legível).

TC10 - Responsividade: Acessar a aplicação em diferentes tamanhos de tela (desktop, tablet e smartphones em modo retrato e paisagem) para garantir que nenhum botão ou painel de resultado fique cortado ou sobreposto.

TC11 - Feedback visual/Animação: Se houver animação de dados rolando ou efeitos sonoros, verificar se eles sincronizam corretamente com o resultado final e não travam a interface.

4. Testes de Estado e Histórico
TC12 - Histórico de rolagens: Se a aplicação possuir um registro de rolagens anteriores, verificar se a lista atualiza na ordem correta (geralmente a mais recente no topo) e se apaga ou mantém os dados adequadamente.

TC13 - Comportamento ao recarregar a página (F5): Atualizar a página após realizar algumas rolagens para verificar se o estado é limpo ou se há persistência indesejada/desejada (via cache/localStorage).

5. Testes de Compatibilidade
TC14 - Navegadores: Executar os testes principais nos navegadores mais populares do mercado (Google Chrome, Mozilla Firefox, Microsoft Edge e Safari).

💡 Dica de Ouro para o seu teste: Anote sempre os passos para reproduzir (Passo a passo), o resultado esperado e o resultado obtido caso encontre algum comportamento inesperado (bug).

Se precisar de ajuda para detalhar algum cenário específico ou focar em alguma funcionalidade própria que o site tenha, é só avisar!
